# 渲染入口与画面编辑

打开网页后，先输入谱面 ID，或选择 `.osr` / `.mr` / `.mrv` 回放，再点击「渲染」。Malody 回放需要上传对应的 `.mcz` / `.osz` / `.zip` 谱面包，包内应包含谱面和音频。曲包有多个难度时，先选择难度再继续。

入口采用左右分区：左侧显示本次输入摘要，右侧填写在线谱面 ID、选择回放与本地谱面包。两个文件区域可点击、用键盘选择或拖放文件，显示文件名、大小与格式，并可分别清除。拖入格式错误或多个文件时保留原选择并提示原因。只上传谱面包可自动播放；已有谱面包时优先使用包内难度。填写 ID 后按 Enter 也可开始。

加载页按实际处理流程标记“读取输入 → 准备皮肤 → 加载谱面 → 音频与背景”，同时显示处理详情。动画使用下落音符的轨道形态，不显示虚构百分比；系统开启减少动画时保留静态轨道与步骤提示。导入后需要选择难度时显示普通提示，选择后复用该包；失败后保留文件和输入，支持直接重试。

入口模块为 `mania-web/src/source-ui.js` 与 `source-ui.css`。该模块仅管理入口交互与加载呈现，继续使用原有回放解析、谱面包导入和渲染流程。自动化入口的 `#fOsr`、`#fMap`、`#bidInput`、`#btnLoad` 等选择器保持可用。

加载期间显示动画和当前步骤，完成后进入播放器。失败会回到输入界面并显示原因，可以修改后重试。播放器控制面板中的「更换谱面 / 回放」可返回入口。

## 播放控制抽屉

保留屏幕底部的抽屉设计：鼠标靠近底边展开，离开自动收起；正在输入参数时保留原有短暂输入保护。底部增加可见的“控制面板”入口，触屏点击或键盘 Enter 可展开，收起按钮与 Escape 可关闭。触屏不响应模拟的鼠标悬停事件；入口页显示期间不会误展开播放抽屉。拖动进度或画面滑块时保持展开，到松手后恢复正常行为。

抽屉分为播放操作、歌曲进度、皮肤、播放参数、画面设置和底部音量/导出操作。滑块显示当前值及已调整部分；播放、暂停、选中与禁用状态有独立反馈。沿用现有按钮 ID、播放器状态、皮肤导入和导出逻辑。音量圆环支持点击、方向键以及 Home/End。

展开/收起使用原生 rAF 的临界阻尼模型，切换方向时保留当前位移与速度；动画结束后停止运行。系统开启减少动画时直接切换到目标位置。关闭的抽屉使用 inert，键盘不会进入不可见控件。样式与动效模块分别为 `mania-web/src/drawer-ui.css` 和 `drawer-ui.js`。

验证：`node renderer/tools/test_drawer_motion.mjs` 检查 30/60/120 fps 一致性、收敛与快速切换的连续性；入口浏览器验证同时调用 `tools/check_drawer_ui.cjs`，检查悬停展开、离开收起、实际播放/暂停、进度、倍速、画面滑块、音量、键盘、触屏和减少动画。另使用后台渲染采用的本地谱面 ID 自动化方式完成载入，保证回复谱面包后的渲染入口兼容。

点击「编辑布局」，可拖动组件、拖动右下角缩放，或填写位置与尺寸。支持连击、难度名称、BPM、歌曲进度、准确率、每秒按键、判定统计和判定条。还可设置显示状态、不透明度、自定义文字与颜色；文字留空时使用实时数据。

布局自动保存在当前浏览器，可重置单个组件或全部组件。网页导出使用当前布局；不同浏览器、QQ 后台渲染任务不会共享个人浏览器的布局设置。

选择「判定条」组件可调整「光柱大小」（0.5–4.0 倍），只改变条上打击标记的宽高，保留其对应的时间偏差位置。标记两端为圆角，5 秒内逐渐淡出；颜色沿用实际回放判定：MAX 白、300 黄、200 绿、100 蓝、50 粉、MISS 红，Malody 使用对应的 BEST / COOL / GOOD / MISS。条上区间宽度使用当前谱面的实际判定窗口。自定义文字颜色只影响文字，不覆盖判定颜色。

三角形显示最近 5 秒打击的平均偏差，按同一渐出权重计算，旧打击会逐渐退出平均；正数在右侧、负数在左侧。仅在真实按下时间后计入有效打击，不计空按或长条松手。暂停、拖动进度与视频导出均使用相同播放时间计算。验证：`node renderer/tools/test_error_bar.mjs`。

三角形置于光柱上方，随光柱高度自动避让。浏览器验证 `node renderer/tools/test_error_bar_browser.cjs <回放.osr>` 检查真实 owc 回放的绘制颜色、圆角和透明度、三角形位置变化，以及大小调整、刷新恢复和重置。

平均标记使用尖端朝下的倒三角。新打击在 180 毫秒内按 smoothstep 曲线逐渐加入平均，位置连续变化，避免每次按下时瞬移。缓动直接按谱面时间求值，不依赖上一帧位置；30/60/120 fps、暂停、跳转进度与视频导出得到相同位置。

「判定条不透明度」控制条的区间、中心线、文字和平均倒三角；「光柱不透明度」单独控制打击标记。两项均可设为 0–100%，默认 100%，互不相乘：最终光柱透明度仅为光柱不透明度 × 随播放时间递减的渐出透明度。判定条设为 0 后仍可显示光柱，光柱设为 0 后仍可显示判定条。设置自动保存，重置判定条时恢复默认值；整个组件的「显示组件」开关仍同时控制所有内容。

编辑布局面板、字段、按钮、复选框、滑块与选中框统一沿用播放器的深色与薄荷绿配色，保留拖动、缩放、自动保存和键盘操作。

## 开场与成绩页

原有皮肤开场箭头向下移动并淡出，重复两次，每次 650 毫秒。时间按首个音符进入画面计算，两次动画至少提前 0.5 秒结束；前奏不足时自动补充预备时间，期间不提前播放音乐。箭头继续使用每套皮肤自身的 `mania-warningarrow` 素材。

最后一个音符结束后续播 2 秒音乐，然后在网页用 650 毫秒淡入成绩卡，无需刷新或跳转页面。视频导出在这 2 秒音乐结束时停止，不包含成绩图或转场，也不依赖成绩图生成成功。拖动进度、重置、暂停与导出使用相同的谱面时钟。

成绩卡通过本地 `/api/result_card` 接口，直接复用 AstrBot `p` 的 `layer_mapping.json`、立绘、字体、标题换行、密度曲线与 Pillow 绘制模块。OSR 使用文件内的分数、最高连击、最终判定与日期，MR/MRV 使用文件内的原生数据；缺少的 PP / TOTAL PP 显示 `--`，自动播放明确标为 Auto Play。Malody 保留自身准确率计算。

部署时模板默认位于工作区 `template/`，绘制模块位于 `plugins/astrbot_plugin_osu_scorecard/`；独立运行副本可在自身根目录放置相同目录，或用 `MANIA_SCORE_TEMPLATE`、`MANIA_SCORE_PLUGIN_DIR` 指定位置。只需打包纯绘图模块和素材，无需携带插件配置、账户数据或 OAuth 凭据。素材缓存与临时文件放在渲染器自身的 cache 下。

验证：`node renderer/tools/test_scene_flow.mjs` 检查开场截止时间、两次循环、倍速与过渡；`node renderer/tools/test_scene_flow_browser.cjs` 验证音乐尾段、网页成绩页淡入和带音频 MP4 导出，解码末帧确认仍为游玩画面。`test_web_release.cjs` 用临时生成的 DT + HO 谱面与回放验证网站，不上传玩家的原始回放；网站地址可通过 `OM_TEST_BASE` 指定。

## 网页导出流程

网页点击「导出」时优先走 WebCodecs：主线程按固定 60 fps 的时间点计算并绘制画面，将 WebGL 游戏画布与 Canvas 2D HUD 合成，再提交给浏览器 VideoEncoder 编码 H.264。编码通过异步回调产出数据；绘制循环定期让出主线程，并根据编码队列大小等待。视频完成后编码 AAC 音频，在网页内合成 MP4 并下载。速度取决于设备，可以快于歌曲实际时长；这不是将不同帧分配给多个 Worker 的并行渲染。

代码使用 WebGL2 图形渲染，没有调用 NPU / WebNN，也没有强制选择视频硬件编码器；实际图形与编码是否获得硬件加速由浏览器、驱动及运行环境决定。浏览器缺少 VideoEncoder 时退回 MediaRecorder，按实际播放时间录制。机器人任务则将视频编码数据分批传到渲染服务，由服务使用 FFmpeg 合成音频与最终视频。

判定条默认宽高均为原来的 1.5 倍，记录逐渐淡出。皮肤光柱与音符共用皮肤解析后的列位置和列宽，高度按贴图尺寸计算；打击闪光按每列的 `LightingNWidth` / `LightingLWidth` 配置或原始贴图尺寸计算，中心使用同一列与判定线。光柱松手后在 250 毫秒内淡出。现有打击 T 图层仍使用原来的音符生命周期。

2026-10-14 位置检查：较早的改动曾独立将光柱与打击闪光放大 1.5 倍，导致 owc 的 130.5 宽音符列上出现 195.75 宽光柱。已移除该额外缩放与光柱左右偏移，统一遵循所有皮肤自身的几何配置；不按皮肤名称设置例外。入口与抽屉的界面改动未修改这些音符坐标。回归验证 `tools/test_skin_effects.cjs <回放.osr> --all` 使用实际绘制矩形检查 owc、R Skin、boj、Cho 与新导入的不等列宽皮肤，同时确认抽屉展开不改变游戏画面坐标。

新增模块为 `mania-web/src/hud-layout.js`，样式为 `mania-web/src/workspace-ui.css`。后台渲染驱动在上传回放后显式点击渲染；机器人已解析的本地谱面包通过自动化入口加载。

验证：`node renderer/tools/test_hud_layout.mjs`、`node renderer/tools/test_hit_traces.mjs`；另完成真实 MRV 与曲包的浏览器加载、难度选择、失败重试、拖动缩放、刷新恢复，以及实际自动播放和 OSR 回放视频导出。
