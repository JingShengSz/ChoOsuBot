# 网页显示打击

在 OM 网页加载 `.osr`、`.mr` 或 `.mrv` 回放后，底部控制面板的「显示打击」按钮可以随时开关，默认关闭。没有回放时按钮不可用。

开启后，原皮肤画面变暗，真实按键显示为高亮 T 形标记：横线对应按键时间，竖线连接谱面音符时间与按键时间。零偏差仍保留短竖线。空按显示红色；没有实际按键的漏键不会凭空生成按键标记。

LN 显示头部 T、按键持续线、按住时判定线上的横线，以及真实松手时的收尾 T。松手标记连接谱面尾部时间与实际松手时间；osu 使用现有尾部判定颜色，Malody 没有独立尾部判定时沿用头部记录的颜色。没有松手事件时不伪造收尾；后续重新按下的松手也不会接到前一个 LN 上。

LN 收尾固定为正 T：横线放在两个时间坐标的上端，竖线向下连接另一个时间坐标；提前、准时或延迟松手都保持该方向。准时松手保留一小段竖线。

打击层在 HUD 画布最后绘制，覆盖皮肤、判定文字和误差条；网页播放和视频导出使用相同的叠放顺序。

打击层与 Note 共用消失条件：普通 Note 被消耗时移除对应 T；LN 到谱面尾部结束时移除其持续线和收尾标记，即使回放没有松手事件也不会残留。所有标记裁剪到判定线以上。提前松手的偏差连接线可随尚未结束的 LN 收缩，到尾部一起消失；拖回进度时按时间重新绘制。

判定颜色沿用 Mania-Replay-Master：白、黄、绿、蓝、粉、红，分别对应 perfect、great、good、ok、meh、miss。MRV 使用已经读取的游戏判定结果，osu 回放使用现有匹配器的判定结果。

标记共用皮肤解析后的列位置、列宽、间距、判定线和时间投影；更换皮肤或流速时重新投影。开关不修改音频、时钟、进度、连击或判定统计。网页导出沿用同一个画面绘制流程，包含当前开启的打击层。

此改动把打击显示加入 OM 网页；独立 `v` 指令仍使用原有 Mania-Replay-Master 渲染入口。

验证：`node renderer/tools/test_hit_traces.mjs` 和 `node renderer/tools/test_malody_replay.mjs`。另用真实 MRV 的 2275 次按键在 R Skin、Cho、boj 三套皮肤和 19/30 流速下完成浏览器验证，包括播放中与暂停时切换。

LN 补充验证使用可控回放输入，在 Stable/Lazer 两种判定模型与 boj/R Skin 两套皮肤中检查持续、提前松手、收尾；用 HUD 不透明遮挡测试确认最终像素仍是打击颜色。
