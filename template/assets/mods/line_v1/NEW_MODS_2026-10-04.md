# osu!mania MOD 线稿图标补齐记录

根据用户提供的四张 MOD 菜单截图，沿用 BPM / OD / HP 与已有 `line_v1` MOD 图标的规范：透明背景、512 × 512 画布、灰蓝色 `#A8B2C4`、统一圆角线条。以下图标为本次新生成；此前已存在的文件没有覆盖。

| 分类 | 本次新生成的 MOD |
| --- | --- |
| Difficulty Reduction | DC Daycore、NR No Release |
| Difficulty Increase | FI Fade In、CO Cover、AC Accuracy Challenge |
| Conversion | RD Random、DS Dual Stages、MR Mirror、DA Difficulty Adjust、IN Invert、CS Constant Speed、HO Hold Off |
| Fun | WU Wind Up、WD Wind Down、MU Muted、AS Adaptive Speed |

截图中其余 11 个 MOD（EZ、NF、HT、HR、SD、PF、DT、NC、HD、FL、CL）已有图标。工作区原有的 SO Spun Out 也保留，因此总计 28 个。

## 文件命名

每个 MOD 以小写缩写命名：`mod_<缩写>.svg`、`mod_<缩写>.png`、`mod_<缩写>_32.png`、`mod_<缩写>_40.png`、`mod_<缩写>_64.png`，均放在当前目录。带缩写文字的成品放在 `../ready/`，名称为 `mod_<缩写>.png` 和 `mod_<缩写>@4x.png`。完整清单见 `manifest.json`，总览见 `preview_complete.png`。

生成脚本：`../../../build/make_missing_mod_line_icons.cjs`。脚本遇到已存在的完整资源组会跳过；遇到不完整资源组会报错，避免覆盖其他对话生成的文件。
