## 风格基线（从 S 立绘反推的，必须保持一致）

| 项 | 规格 |
|---|---|
| 画风 | 柔和动画 / VTuber 主视觉风，cel 阴影 + 柔和渐变，不是厚涂 |
| 线条 | 干净利落的细线，深蓝黑描边，不要潦草速写感 |
| 上色 | 高饱和但不刺眼，高明度，整体偏亮 |
| 构图 | 半身到大腿为主，人物在牌**后面或侧面**，手搭在牌上 |
| 牌 | **木纹木牌**，正面写着评级字母（金色、立体感）+ 下方小字 `RANK` |
| 背景 | **纯色绿幕**，不带任何阴影、渐变、地面 |
| 画布 | 竖构图，人物头顶留白约 5%，底部切到牌的下缘 |

### 绿幕那一条最重要

- 纯 `#00FF00` 一类的**绝对均匀**绿，不要有明暗变化、不要有地面阴影
- 人物不要穿大面积纯绿色，否则会被一起抠掉
- 头发、飘带这类细碎边缘尽量和绿色拉开对比

## 六张的提示词

把 `{角色}` 换成你想用的角色。**六张用同一套模板**，只改角色和字母，风格才不会飘。

### 通用模板

```
柔和的日系动画风格全身插画，{角色}，
站在一块竖放的木纹木牌后面，双手搭在木牌上沿，
木牌正面是一个立体的金色大写字母「{字母}」，下方有金色小字「RANK」，
cel 阴影上色，干净利落的细线描边，高饱和明亮配色，
人物完整的从头到脚都在画面内，头上留一点空间，
纯色绿幕背景（#00FF00），背景上没有任何阴影、渐变、地面，
竖构图，full body anime illustration, cel shading, clean line art,
flat pure chroma key green screen background, no shadow on background
```

### 六张分别填

| 评级 | 字母 | 建议角色方向 | 色调建议 |
|---|---|---|---|
| **XH** | `XH` | 最强、最张扬。双人/带翅膀/发光特效 | 金 + 白，最高亮度 |
| **SS** | `SS` | 优雅、冷静 | 金 + 深紫 |
| **SH** | `SH` | 和 SS 同角色不同姿态（银色调） | 银 + 冰蓝 |
| **A** | `A` | 元气、活力 | 橙 + 青 |
| **C** | `C` | 慵懒、随意 | 紫 + 灰 |
| **D** | `D` | 反差萌、委屈或摆烂 | 红 + 暗蓝 |

`XH` / `SS` / `SH` 是**双字母**，木牌上的字母要相应变宽 —— 提示词里直接写
「金色大写字母「XH」」，不要让 AI 自己缩写。

## 出图后

```bash
cd osu-score-card/template/build
python make_signboard.py 你的图.png XH --preview
```

会自动：抠绿幕 → 裁到人物墨迹 → 缩到宽 643px → 贴到画布右下（右边 1920、底边 1080）
→ 输出 `signboard_XH.png` + 一张深色底预览。

看预览确认没问题，再告诉我，我一次性装进 PSD 的 `signboard_xh` 图层。

**自检数字**：抠完 `alpha` 行会打印占比。
正常立绘不透明 20%~60%；小于 5% 说明绿幕判定失效（多半是角色本身有绿色）；
大于 85% 说明绿幕没抠干净。前者调 `--tol`，后者一般是背景不是纯色，得重出图。

## 为什么不用 Photoshop 内置的 Firefly

试过一次（`photoshop_generate_image`）：请求超时，Photoshop 忙了两分钟，
最后**没有产生任何新文档**，什么都没出来。

更关键的是风格问题：现有 S 和 B 是同一个模型出的，画风统一。
Firefly 出的图大概率是另一种笔触和上色，八张卡摆在一起会明显不搭 ——
同一张卡上两张立绘风格不一致，比缺六张还难看。

所以这六张建议还是用你原来那个（`qwen-agent` 的 visual）出，风格能对上。
