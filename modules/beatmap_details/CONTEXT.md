# 谱面详情

描述 osu!mania 谱面内容及分析指标，供玩家了解谱面结构与难度。

## Language

**谱面详情**：单个难度的谱面信息、结构指标及难度分析结果。

**Detail Pro**：谱面详情的完整展示版本，包含三页信息与图表。

**详情聊天记录**：按页面顺序收纳 Detail Pro 三页图片的合并转发消息。

**静态谱面分析**：只根据谱面内容与指定的客户端、Mod 得出的分析，不依赖某一次游玩的成绩。

**实时游玩指标**：依赖某次游玩的判定、进度或暂停状态的指标。

**估算难度**：算法对谱面难度的预测；应保留算法名称，不能当作官方星数。

**RC**：以单点音符为主要分析对象的键型类别。

**LN**：以长条音符为主要分析对象的键型类别。
